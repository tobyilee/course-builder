# 대상 학습자

- **Audience:** TypeScript / JavaScript / React UI 컴포넌트 개발은 능숙한 중급 개발자. 함수형 컴포넌트, useState 기본 사용, 이벤트 핸들링, props 흐름은 이미 안다. 다만 state 설계·구조화·공유·보존·리듀서·컨텍스트 영역에서 깊이가 부족하다.
- **Depth:** deep
- **Language:** ko
- **Tone:** friendly

## 전제조건
- 함수형 컴포넌트 작성 경험 (props, children, 이벤트 핸들링)
- useState 훅 기본 사용 — 원시값/객체/배열 모두
- JavaScript ES2015+ (구조 분해, 스프레드, 화살표 함수, 모듈)
- TypeScript 또는 modern JavaScript의 타입/구조 감각
- JSX 렌더링과 조건부 렌더, 리스트의 key prop 기본 개념
- 불변 갱신(spread, map/filter)에 대한 익숙함
